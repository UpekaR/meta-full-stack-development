The purpose of this folder is to organize my full-stack development learning in one place, including:

- Front-end development fundamentals
- HTML and CSS
- JavaScript programming
- Git and GitHub version control
- React and Advanced React
- Python programming
- Databases for back-end development
- Django web development
- APIs
- Full-stack application structure
- Practice exercises and projects

This learning path is also important for improving my university Web Technologies knowledge and building stronger practical skills for IT job opportunities.
