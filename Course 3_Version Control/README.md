# Version Control 

This folder contains my notes, quiz summaries, and practice work from the **Version Control** course in the Meta Full-Stack Development learning path.

This course focuses on how developers use version control systems like Git and platforms like GitHub to track changes, collaborate safely, manage project history, and work professionally in software development teams.

---

## 🎯 Course Purpose

The purpose of this course is to understand how version control supports software development.

Through this course, I am learning how developers:

- Track changes in code
- Save project history
- Work with repositories
- Use the command line
- Collaborate with other developers
- Manage branches
- Resolve conflicts
- Use Git and GitHub in real projects
